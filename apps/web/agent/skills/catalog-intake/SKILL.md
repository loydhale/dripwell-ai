---
description: Organize an owner's menu, pricing, recorded notes, or catalog image into a reviewable clinic setup proposal and identify missing details.
---

1. Read the current draft and active configuration through read_configuration.
2. Separate products/add-ons, other services, and memberships. Preserve supplied names, exact source prices/currency, benefits, and terms.
3. Flag conflicting prices or uncertain image text for confirmation. Never estimate an official price.
4. Ask about required intake questions and clinically validated eligibility/exclusions. Owner pricing approval alone is not clinical validation.
5. Store a structured proposal using propose_draft with cited source and remaining gaps. Never publish configuration.
6. Explain that the owner can review/edit settings, run synthetic cases, and activate a tested version. Tests never consume trial consultations.
